======
ci-aio
======

This environment deploys an all-in-one converged control/compute cloud for CI
testing.

It inherits from the ``aio`` environment, with CI-specific overrides for
internal ``stackhpc-kayobe-config`` development.

For instructions on deploying your own all-in-one instance. See the :doc:`aio
environment <aio>` documentation for more information.

   All-in-one GitHub CI testing using this environment is further described
