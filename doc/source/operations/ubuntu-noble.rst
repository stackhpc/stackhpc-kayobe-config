============
Ubuntu Noble
============

.. warning::

  Before upgrading to the 2025.1 release of OpenStack, all Ubuntu hosts must first be upgraded to Ubuntu Noble (24.04).
  Please follow the upgrade instructions provided in the 2024.1 release documentation, available `here <https://stackhpc-kayobe-config.readthedocs.io/en/stackhpc-2024.1/operations/ubuntu-noble.html>`__.
